# 标注工作台集成方案：X-AnyLabeling（桌面） + Label Studio（Web） × ccd-train

> 目标：标注工作台不重复造轮子——**桌面端**嵌入开源 **X-AnyLabeling**（Qt 标注器），
> **网页端**嵌入开源 **Label Studio**（Web 标注平台），标注结果统一回写 ccd-train
> 后端，训练流水线零改动。数据闭环（导出导入）作为兜底方案。

---

## 〇、两条嵌入路线总览

| 端 | 方案 | 状态 |
|---|---|---|
| 桌面端（Qt） | 嵌入 X-AnyLabeling `LabelingWidget`（画笔/多边形/SAM/缩放平移） | ✅ 代码已就位（待装依赖） |
| 网页端（Vue） | iframe 嵌入 Label Studio（Brush/SAM2/多边形） | ✅ 代码已就位（待装依赖） |

> 说明：X-AnyLabeling 是 PySide6 桌面程序，无法嵌入浏览器；
> Label Studio 是 Web 平台，无法嵌入 Qt——两者互补，各自负责一端。

## 一、为什么选它们

| 需求 | X-AnyLabeling | ccd-train 自研（替换前） |
|---|---|---|
| 滚轮缩放 + 左键平移 | ✅ 像素级缩放、浏览模式平移 | Web 端有；桌面端仅有 1.15x 滚轮、无平移 |
| 画笔逐像素 + 橡皮擦 | ✅ 笔刷/橡皮擦/填充 | 桌面端画笔有、橡皮擦只能删整条 |
| SAM 智能标注 | ✅ 内置 SAM/SAM2/EdgeSAM 等（点/框提示） | 后端有 MobileSAM API，桌面端未接 |
| 范围标注 | ✅ 矩形/多边形/椭圆/折线/点 | 桌面端只有画框 |
| 多任务 | ✅ 检测/分割/分类/视频 | box/mask/class/shield |

- 项目：[CVHub520/X-AnyLabeling](https://github.com/CVHub520/X-AnyLabeling)（10.2k stars，活跃维护）
- 架构：PySide6 桌面应用，核心组件 `LabelingWidget`（画布 + AutoLabelingWidget）可嵌入
- 最新版：**v4.0.4**（PyPI 包名 `x-anylabeling-cvhub`）

## 二、总体架构

```
┌─────────────────────────── ccd-train 桌面端 ───────────────────────────┐
│ 标注标签页 XalLabelingPage                                              │
│   工具栏：数据集下拉 + [导出] [回写保存] [打开镜像目录]                    │
│   ┌──────────────────────────────────────────────────────────┐         │
│   │  LabelingWrapper（X-AnyLabeling 嵌入，PyQt6→PySide6 shim）│         │
│   │  画笔/橡皮擦/多边形/椭圆/SAM/缩放平移 …                    │         │
│   └──────────────────────────────────────────────────────────┘         │
└──────────────┬───────────────────────────────────┬──────────────────────┘
               │ ① export_dataset                    │ ② import_dataset
               ▼                                     ▼
    backend/data/xal_mirror/<数据集名>/      LabelMe JSON（foo.json）
    图像（符号链接）+ LabelMe JSON           → 解析 → 后端 annotations API
                                           （全量重建 box/mask/shield）
```

**数据映射**（见 `desktop/xal_sync.py`）：

| ccd-train 后端 | X-AnyLabeling（LabelMe JSON） |
|---|---|
| `box` {x1,y1,x2,y2} | shape_type=`rectangle`，points=两角点 |
| `mask` {points:[[x,y],…]} | shape_type=`polygon` |
| `shield`（屏蔽区，不参与训练） | 标签名 **`__shield__`** 的多边形 |
| `class`（整图分类） | 不支持（导出跳过、回写保留，分类仍用原平台/Web） |
| 类别 | 按**名称**匹配：X-AnyLabeling 里新建标签名须与数据集类别名一致 |

## 三、实施步骤（已完成 ✅）

### 1. X-AnyLabeling 源码（已就位）

- 源码解压于 `third_party/x_anylabeling_cvhub-4.0.4/`（PyPI sdist 包，Apache-2.0）
- 运行时依赖已装入 `backend/.venv`（cv2/numpy/onnxruntime/ultralytics + 轻量依赖）
- **PyQt6 → PySide6 兼容层**：`desktop/qt6_compat.py`（sys.modules 映射 +
  pyqtSignal/pyqtSlot 别名 + uic 预编译 + 资源模块别名），X-AnyLabeling
  无需改 import 即可跑在 ccd-train 的 PySide6 上

  - `navigator_widget.py`：多重签名信号 `pyqtSignal([int],[int,QPoint])` 拆为
    `zoom_changed` / `zoom_changed_with_pos`
  - `utils/qt.py`：`new_action` 的 triggered(bool) 语义用包装器还原

## 四·五、网页端集成（X-AnyLabeling 代码级复用，替代 Label Studio iframe）

> 网页端标注全程在 ccd-train 自己的页面完成，不跳转任何外部应用。
> X-AnyLabeling 的 Python 几何/掩码算法被复用到后端；前端自研画布
> （已有缩放/平移/画笔/橡皮擦/SAM）补齐多边形/椭圆工具。
> 原先的 Label Studio iframe 方案已拆除（脚本保留在 `labelstudio/` 可作备用）。

### 复用的 X-AnyLabeling 代码

| 后端文件 | 来源（Apache-2.0） | 复用的能力 |
|---|---|---|
| `backend/app/xal/geometry.py` | `views/labeling/utils/shape.py` + `utils/opencv.py`（去 Qt 化） | 形状→掩码（圆/矩形/多边形/线/点）、掩码→bbox、圆/椭圆→多边形采样、对角线→矩形 |

| 新增 API | 作用 | 前端使用 |
|---|---|---|
| `POST /api/xal/ellipse` | 椭圆（圆心+边缘）→ 32 边多边形 | 「椭圆」工具 |
| `POST /api/xal/circle` | 圆 → 正多边形 | 「椭圆」工具特例 |
| `POST /api/xal/mask/bbox` | 掩码 → 最小外接框 | 检测标注辅助（可后续接「掩码自动出框」） |
| `POST /api/xal/shape/mask` | 任意形状 → 掩码校验/转换 | 格式转换 |

### Web 标注页新增工具（Labeling.vue，已重新构建 dist）

- **多边形**：左键逐点加点 →「完成多边形」/双击闭合 / Esc 取消 → 存为 mask 标注
- **椭圆**：拖拽画椭圆 → 调 `/api/xal/ellipse` 生成 32 边多边形 → 存为 mask 标注

### 已验证（2026-08-26，数据集 12 实测）

- `/api/xal/ellipse`：圆心(100,100)+边缘(160,130) → 32 点，rx=60/ry=30 精确 ✅
- `/api/xal/mask/bbox`：三角形掩码 → (10,10,101,61) ✅
- Web 页面浏览器实测：多边形模式点 4 顶点 → 完成 → 后端生成 mask 标注（4 点多边形，类别正确）✅
- 工具条：画框/多边形/椭圆/分类/SAM 掩码/画笔/橡皮擦/掩膜/平移 ✅

### 备用（如需独立 Web 标注平台）

`labelstudio/` 下的脚本仍保留：Label Studio 独立部署 + `sync_ls.py` 双向同步，
可作为团队协作标注的备用方案，但不再嵌入 ccd-train 页面。

## 五、兜底方案（轨道 A，零代码）

不嵌入时直接用独立 exe 标注：

1. X-AnyLabeling 打开后端数据集目录（`datasets.root_path`，图像本就在磁盘）
2. 按数据集类别名建标签，标注
3. 导出 LabelMe JSON（或 COCO/YOLO）
4. 平台内调用已有导入 API：
   `POST /api/datasets/{id}/import-annotations  {"format": "labelme", "path": "<json 目录>"}`
5. 训练中心直接使用

## 六、风险与注意

- **镜像目录**：导出为符号链接（失败自动降级复制），占用空间小；回写后镜像目录
  可删除，下次导出重建。
- **SAM 标注冲突**：回写是全量重建（删除该图所有 box/mask/shield 再写入），
  Web 端 SAM 生成的标注也会被镜像目录中的状态覆盖——两处不要同时标注同一数据集。
- **类别变更**：X-AnyLabeling 中标签名与后端类别名不一致的 shape 会被跳过并在
  回写结果中列出。
